# git clone

El comando `git clone` se utiliza para crear una copia local exacta de un repositorio de Git que ya existe en un servidor remoto, como por ejemplo en Github. A diferencia de `git init`, que se usa para iniciar un proyecto completamente nuevo desde cero en una carpeta local vacia, `git clone` se emplea para descargar un proyecto que ya está en marcha. Al utilizarlo, no solo se descargan los archivos de código, sino que tambien se trae todo el historial de commits anteriores y las ramas existentes.

Este comando es indispensable cuando te sumas a un equipo de trabajo o cuando necesitas continuar desarrollando desde otra computadora. Por ejemplo, si quisieras bajar a tu entorno local un repositorio, usarias este comando para traerte toda la estructura del proyecto y empezar a programar sin tener que configurar nada a mano.

### Ejemplo de uso

`bash`
`git clone URL_DEL_REPOSITORIO`
