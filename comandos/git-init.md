# git init

El comando `git init` es el primer paso fundamental para comenzar a usar Git en un proyecto nuevo. la funcion principal es transformar una carpeta comun y corriente de la computadora en un repositorio local de Git. Esto se utiliza cuando se arranca un desarrollo desde cero. Por ejemplo, si tenés una carpeta local con los archivos HTML y CSS para una tienda de ropa y queres empezar a registrar el historial de todas las modificaciones que vayas haciendo en el código.

Al ejecutar este comando, git crea de forma automática una subcarpeta oculta llamada `.git` dentro del directorio en el que estás ubicado. Esta carpeta contiene toda la configuración y los archivos necesarios para que Git pueda empezar a rastrear los cambios, gestionar las ramas y guardar los commits de ese proyecto en particular.

### Ejemplo de uso

`bash`
`git init`
