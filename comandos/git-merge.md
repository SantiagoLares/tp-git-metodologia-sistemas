## GIT MERGE:

# El comando "git merge" permite unir los cambios de una rama a otra.
# Se utiliza principalmente para incorporar a main el trabajo realizado en una rama en desarrollo.

# EJEMPLO:

# bash
# git checkout main
# git merge feature/nombre-rama

# EXPLICACION: Primero cambiamos a la rama main, luego se incorporan los cambios de la rama indicada a la rama en la que estamos.
