## GIT REVERT:

# El comando "git revert" crea un nuevo commit que deshace los cambios de otro commit.
# La diferencia con git reset es que reset modifica el historial, mientras que git revert conserva el historial y agrega un nuevo commit.

# EJEMPLO:

# bash
# git revert HASH_DEL_COMMIT

# EXPLICACION: Se genera un nuevo commit que revierte los cambios del commit indicado.
